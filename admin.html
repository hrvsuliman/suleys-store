Store Admin

Sign in with a GitHub token to edit your shop. Changes go live about a minute after you publish.

How do I get a token?
  1. Open GitHub → New fine-grained token.
  2. Name it “Store admin” and pick an expiry.
  3. Under Repository access, choose Only select repositories and pick your store repo.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it and paste it here.

The token stays in this browser and is only sent to GitHub. It can only change this one repository.
